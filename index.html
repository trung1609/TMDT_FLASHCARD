DANH MỤC HỌC PHẦN

Chọn học phần muốn ôn tập

Hệ thống ngân hàng trắc nghiệm và câu hỏi tự luận theo từng môn học được phân bổ khoa học, tối ưu ôn thi.

🔍

🛠️ Bạn muốn thêm học phần mới vào kho?

Hệ thống được thiết kế dạng module hóa, rất dễ dàng để bổ sung các môn học tiếp theo.

1

Chuẩn bị câu hỏi

Soạn ngân hàng câu hỏi trắc nghiệm dưới dạng mảng JSON hoặc file data.js có danh sách buổi và câu hỏi.

2

Tạo file môn học

Nhân bản từ tmdt.html sang tên môn mới (ví dụ web.html, csdl.html) và liên kết dữ liệu.

3

Đăng ký vào kho

Mở file courses.js, thêm thông tin học phần vào mảng và đặt status: 'ready'.

📚

Hướng Dẫn Thêm Môn Học Vào Kho

Dành cho sinh viên & quản trị viên biên soạn

Kho Quiz Hub được kiến trúc tách biệt giữa Trang chủ điều hướng (index.html) và Trang ôn tập môn học (như tmdt.html). Các bước triển khai môn tiếp theo:

Bước 1: Khai báo trong courses.js 
{
  id: "cse3020",
  code: "CSE3020",
  title: "Lập Trình Web & Ứng Dụng",
  status: "ready", // hoặc "coming_soon"
  url: "web.html",
  icon: "🌐",
  ...
}
Bước 2: Chuẩn bị file HTML và Data

Chỉ cần sao chép tmdt.html thành web.html, trỏ tới file dữ liệu câu hỏi của môn đó. Mọi tính năng phím tắt, âm thanh, đối chiếu trang gốc, flashcard và đồng bộ đều dùng lại nguyên bản!

Bước 3: Tự động hoàn tất

Khi lưu file, trang chủ sẽ tự động hiển thị học phần mới với đầy đủ tính năng tìm kiếm, thống kê và lưu tiến độ riêng biệt.
